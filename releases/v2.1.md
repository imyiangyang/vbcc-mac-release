# VBCC Mac 2.1（构建号 2）

发布日期：2026-11-03。

## 下载与安装

- 下载附件 `vbcc-mac-v2.1.dmg`，打开后将应用拖入「应用程序」。
- 要求 macOS 13.0 或更新版本；Universal 包包含 Apple Silicon（arm64）与 Intel（x86_64）架构。
- 应用及 DMG 均使用 Developer ID 签名、通过 Apple 公证并附加公证票据。
- 首次使用需授予辅助功能权限，并允许系统提示的本地网络访问；与兼容的 VBCC iPhone 客户端配对后使用。

## Changelog：相对 2.0

### 应用内语言切换

从侧边栏底部「设置」或应用菜单「设置」（Command-逗号）打开原生设置窗口。可选择「跟随系统」或一种指定语言，立即生效，无需重启，并在下次启动时保留。

### 17 种语言与 RTL 支持

界面语言由 8 种扩展至 17 种，新增意大利语、巴西葡萄牙语、俄语、土耳其语、印度尼西亚语、阿拉伯语、印地语、泰语和越南语。补全界面、运行状态、错误提示、应用生成的 Hooks 消息及本地网络权限说明的翻译。

阿拉伯语采用从右到左布局，URL、模型标识和快捷键保持便于阅读的方向。切换语言保留当前页面、连接服务和自定义 Prompt；历史消息、历史日志及用户输入保持原文。

### 模型配置权限优化

修复仅打开「模型配置」页面就请求钥匙串密码权限的问题。配置关闭或使用 Ollama 时不读取豆包 API Key；只有启用豆包并显示密钥字段时才按需读取已有密钥。回填不再触发保存，只有手动编辑才保存；离开页面前会保存尚未完成的编辑，连接测试使用当前填写的内容。

## 功能说明

继续提供远程触控板（指针、点击、双击、拖拽、双轴滚动与惯性滚动）、文字与快捷键输入、Ollama/豆包文本润色、Claude Code/Codex/Cursor Hooks 通知、设备配对与吊销、消息历史和运行日志。

远程触控板需要兼容的 iPhone 客户端；模型服务由用户自行配置，应用不附带模型。
