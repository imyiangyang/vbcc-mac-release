# VBCC Mac 2.0（构建号 1）

发布日期：2026-10-21。此版本为本公开分发仓库的首个发行版，源码继续保存在独立的私有仓库。

## 下载与安装

- 下载附件 `vbcc-mac-v2.0.dmg`，将应用拖入「应用程序」。
- 要求 macOS 13.0 或更新版本；Universal 包包含 Apple Silicon（arm64）与 Intel（x86_64）架构。
- 应用和 DMG 均使用 Developer ID 签名、通过 Apple 公证并附加公证票据。
- 首次使用请授予辅助功能权限，并让 Mac 与兼容的 VBCC iPhone 客户端处于可互通的局域网。

## Changelog

### 本轮发布调整

- 正式开放远程触控板，Release 与 Debug 均可使用，无需开发者偏好开关。
- 新增独立的公开安装包分发仓库、更新记录和功能使用说明。
- 发布签名、公证的 DMG，以及 SHA-256 校验文件。

### 本版本包含的功能

- **远程触控板**：指针移动、左/右键点击、双击、左键拖拽、横纵滚动和惯性滚动；保留配对认证、权限检查与断线清理。
- **文字与快捷键**：把 iPhone 发来的文字写入当前焦点输入框，支持基本按键、修饰键组合及向前删除。
- **可选文本润色**：支持 Ollama 与豆包，可设置模型、提示词和超时，并测试连接。
- **开发工具 Hooks**：支持 Claude Code、Codex、Cursor，转发通知至已连接的 iPhone；Codex 与 Cursor 的新安装配置使用会话结束事件。
- **设备与消息管理**：数字配对、设备吊销、文字和 Hooks 消息历史、运行日志。
- **多语言**：简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语。

以上为本版本功能概览，不表示所有功能均首次在 2.0 中实现。远程触控板需使用支持该能力的 iPhone 客户端。模型服务由用户自行配置，应用不附带模型。
